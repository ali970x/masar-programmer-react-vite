# مسار المبرمج — React + Vite

موقع عربي متكامل لفكرة كتاب **مسار المبرمج**.

## المحتوى

- Hero section للكتاب
- مسارات برمجية تفاعلية
- أطلس أدوات مع بحث وفلاتر
- مقارنات تقنية مثل PostgreSQL vs MongoDB
- Roadmap عام للتعلم
- مشاريع حسب المستوى
- قاموس مصطلحات
- تصميم RTL عربي Responsive

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الـ terminal غالبًا:

```bash
http://localhost:5173
```

## البناء للإنتاج

```bash
npm run build
npm run preview
```

## أهم الملفات

```text
src/App.jsx       واجهة الموقع والأقسام
src/data.js       بيانات المسارات والأدوات والمقارنات
src/styles.css    التصميم الكامل
```
